# Privacidade e proteção de dados no assistente virtual

## Dados que o assistente não solicita
O assistente virtual do Cidade Para Todos não solicita CPF, senhas, dados bancários ou número de cartão. O cidadão não deve informar dados pessoais no chat. Caso informe, o sistema mascara automaticamente CPF, e-mail e telefone antes de processar a mensagem.

## Limites do assistente
O assistente responde apenas com base nos documentos oficiais da base de conhecimento. Ele não substitui o atendimento oficial e não abre protocolos em nome do cidadão.

## Direitos do titular
Para exercer direitos previstos na Lei Geral de Proteção de Dados (LGPD), como acesso, correção e exclusão de dados, o cidadão deve registrar a solicitação pelo canal de Ouvidoria do portal.
